# Changelog for polytropos-aeson

## 0.1.0.0 — Initial Release

- High-performance Aeson `ToJSON` and `FromJSON` codecs for open records and variants
- Heterogeneous record serialization and deserialization via compile-time field dictionary unrolling
- Open variant serialization with $O(1)$ constructor tag dispatch into tagged JSON objects
- Homogeneous record/variant helpers and schema introspection
