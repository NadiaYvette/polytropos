# Changelog for polytropos-persistent

## 0.1.0.0 — Initial Release

- Yesod `persistent` relational database marshalling and entity wrappers for open records
- Fast zero-tuple marshalling between records and `[PersistValue]` rows via `PersistRow`
- `PersistField` and `PersistFieldSql` instances for whole-record column storage
- `PolyRowEntity` wrapper for database entities
