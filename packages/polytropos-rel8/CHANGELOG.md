# Changelog for polytropos-rel8

## 0.1.0.0 — Initial Release

- High-level type-safe PostgreSQL database mapping connecting open rows to `rel8`
- `PolyRow` higher-kinded `Rel8able` schema representation derived from type-level row specifications
- Slot-by-slot conversions between Rel8 columnar tables and flat `SmallArray` row representations
