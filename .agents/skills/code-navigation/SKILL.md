# Token-Efficient Code Navigation & Structural Search

To conserve context window tokens and avoid reading whole files unnecessarily, follow the **Progressive Disclosure Funnel**:

## 1. Symbol Definition Jumps (Level 0 — <15 tokens)

Query the precomputed `./tags` index generated by `hasktags`:

```bash
grep -w "^<SymbolName>" tags
```

*Examples:*
```bash
grep -w "^Rep" tags
grep -w "^RowRep" tags
grep -w "^solveRowEq" tags
grep -w "^fieldAt" tags
```
Instantly returns the exact file path and line number without scanning or opening files.

## 2. Targeted Slice Inspection (Level 1 — <250 tokens)

Do **NOT** view whole files. Use `view_file` with `StartLine` and `EndLine` scoped to the exact slice (e.g. ±15 lines around the symbol definition).

## 3. Structural Pattern Matching with `ast-grep` (Level 2 — <300 tokens)

Use `ast-grep` (`sg`) to search Concrete Syntax Trees directly, ignoring comments, whitespace, and formatting differences:

```bash
# Find all typeclass declarations
sg -p 'class $CLASS $PARAM where $$$METHODS' packages/

# Find all TcPlugin constraint solvers
sg -p 'solve$NAME state ct cls tys = $$$BODY' packages/

# Find all test groups
sg -p 'testGroup $NAME [ $$$TESTS ]' packages/
```

## 4. Semantic Identifier Cross-References with `ripgrep`

To locate call sites and type uses without noise:

```bash
# Search only Haskell source files
rg --type haskell -w "RowRep" packages/

# Search for open questions or design notes across docs and code
rg -w "D[0-9]+" docs/ packages/
```

## 5. Keeping the Index Synchronized

Whenever modules, data types, or functions are added or renamed:

```bash
./bin/generate-tags
```
