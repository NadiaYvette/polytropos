# AI Coding Assistant Attribution Configuration

This configuration specifies the commit attribution schema for AI coding assistants and orchestration engines operating in `polytropos`, adopting the convention established in `sarutahiko`.

## 1. Commit Trailers

Every commit assisted or generated by an AI assistant or workflow engine must include structured RFC 2822 trailers at the foot of the commit message:

```
Assisted-by: <Tool> (<Provider> / <Model>)
Orchestrated-by: <Engine>
```

### Examples
- **Antigravity with Claude:**
  ```
  Assisted-by: Antigravity (Anthropic / claude-4.6-opus)
  ```
- **Antigravity with Gemini:**
  ```
  Assisted-by: Antigravity (Google / gemini-3.8-pro)
  ```
- **Freebuff (unspecified model):**
  ```
  Assisted-by: Freebuff
  ```
- **With Orchestration Engine:**
  ```
  Assisted-by: Utai Native (mistral/codestral-latest)
  Orchestrated-by: Yamaarashi Flow Task Runner
  ```

## 2. Inviolable Legal Rules

- **NO Co-authored-by:** AI tools cannot legally hold copyright or co-author software under open-source licenses.
- **NO Signed-off-by:** Only human developers may sign off and certify the Developer Certificate of Origin (DCO).
- **NO Robot Emojis:** Commit headers and trailers must remain clean, parseable text.
